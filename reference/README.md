# Reference material

The dimensions in `cad/src/lib/params.py` were taken from the manufacturers' listing drawings and the
Xiaomi M8R-FLH filter datasheet. Those images and PDFs belong to their owners, so they are not in the
repository. You'll find them on the product pages:

| What | Where to look |
| --- | --- |
| HEWA Onyx 150 mm (6") exhaust fan: cutout and outline dimensions | The fan's Amazon.in listing, image gallery |
| PANCA HEPA filter for Xiaomi Mi Air Purifier 1/2/3/2H/2S/3H/3C | The filter's Amazon.in listing, image gallery |
| Xiaomi M8R-FLH filter datasheet | Xiaomi's support pages for the Mi Air Purifier filter |

If you keep your own copies here, git ignores them.
